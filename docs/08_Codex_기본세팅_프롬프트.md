# Codex 기본 세팅 프롬프트

이 문서는 GitHub에서 받은 `hwp_manage` 폴더를 Codex로 자동 준비하기 위한 복사·붙여넣기용 문장이다.

## 사용 방법

1. GitHub에서 받은 ZIP의 압축을 푼다.
2. Codex에서 `README.md`와 `AGENTS.md`가 바로 보이는 저장소 폴더를 연다.
3. 아래 **복사할 프롬프트** 상자 전체를 복사해 Codex 채팅창에 붙여 넣는다.
4. Codex가 완료 보고를 할 때까지 기다린다.

## 복사할 프롬프트

```text
이 hwp_manage 저장소를 컴퓨터 초보자가 바로 사용할 수 있도록 기본 세팅해줘. 질문 없이 진행할 수 있는 안전한 작업은 끝까지 진행하고, 아래 순서를 지켜줘.

1. 현재 폴더에 README.md, AGENTS.md, pyproject.toml, scripts 폴더가 있는지 확인해. 없으면 다른 파일을 수정하지 말고, 사용자가 열어야 할 올바른 폴더를 쉬운 말로 알려줘.
2. AGENTS.md, docs/00_총정리_목차.md, docs/01_사용자_매뉴얼.md, docs/08_Codex_기본세팅_프롬프트.md를 먼저 읽고 그 규칙을 따라줘.
3. macOS, Windows, Linux 중 현재 운영체제와 Python 버전을 확인해. Python 3.10 이상이 없으면 설치가 필요한 이유와 공식 설치 방법을 쉬운 말로 안내해. 시스템 전체 설치나 관리자 권한이 필요한 변경은 내 허락 없이 실행하지 마.
4. macOS/Linux에서는 sh scripts/setup.sh를 실행하고, Windows에서는 powershell -ExecutionPolicy Bypass -File scripts\setup.ps1을 실행해. 설치가 실패하면 오류 원인을 확인하고 저장소 안에서 안전하게 고칠 수 있는 문제만 고친 뒤 다시 시험해. 성공하지 않았는데 성공했다고 말하지 마.
5. 설치 스크립트의 자동 테스트가 모두 통과했는지 확인해.
6. macOS/Linux에서는 sh scripts/run_sample.sh를, Windows에서는 powershell -ExecutionPolicy Bypass -File scripts\run_sample.ps1을 실행해. 샘플 결과의 passed가 모두 true인지 확인해.
7. 저장소 바로 아래에 다음 빈 폴더를 만들어줘.
   - 사용자작업/목표2/국어 자료 변형 중간모음터
   - 사용자작업/목표2/국어 자료 PDF 조각
   최종본 폴더는 실제 pipeline이 만들게 두고, 합성 샘플이나 실제 교재 파일을 사용자작업 폴더로 복사하지 마.
8. 사용자작업 폴더는 Git에 올라가지 않도록 .gitignore의 사용자작업/ 규칙이 적용되는지 확인해.
9. 원본 HWP/HWPX를 수정·삭제·이동하지 마. .hwp를 자동으로 .hwpx로 변환하지 마. 실제 사용자 파일의 pipeline은 아직 실행하지 마.
10. 마지막에 아래 항목을 컴퓨터 초보자도 이해할 수 있는 한국어로 보고해.
   - 사용 중인 운영체제와 Python 버전
   - 자동 테스트 통과 여부
   - 샘플 병합·검증 통과 여부
   - 내가 HWPX 파일을 넣어야 하는 정확한 폴더 위치
   - 다음에 Codex에 보낼 실제 작업 프롬프트

모든 검사가 통과했을 때만 “기본 세팅 완료”라고 말해줘. 중간에 막히면 어려운 전문용어 대신, 내가 눌러야 할 버튼이나 해야 할 행동을 한 단계씩 알려줘.
```

## 세팅 뒤 실제 작업 프롬프트

HWPX 파일을 `사용자작업/목표2/국어 자료 변형 중간모음터/{책 이름}/{단원}/`에 넣은 뒤 아래 문장도 그대로 사용할 수 있다.

```text
AGENTS.md와 docs/00_총정리_목차.md를 먼저 읽어줘.
사용자작업 폴더에 넣어 둔 모든 책을 확인하고 원본은 수정하거나 삭제하지 마.
doctor와 inventory로 입력을 먼저 점검한 뒤 pipeline을 실행하고, verify를 별도로 다시 실행해줘.
PDF 조각 폴더에 PDF가 있으면 pipeline에 --pdf 옵션도 사용해줘.
모든 passed가 true일 때만 완료라고 말하고, 제출용 폴더와 ZIP의 위치를 책별로 알려줘.
문제가 있으면 결과를 덮어쓰지 말고 원인과 내가 해야 할 일을 쉬운 말로 설명해줘.
```

## 완료 확인 기준

Codex의 마지막 보고에 다음 세 문장이 모두 있어야 한다.

- 자동 테스트 통과
- 샘플 병합·검증 통과
- 사용자작업 폴더 준비 완료

하나라도 실패했다면 [사용자 매뉴얼의 자주 생기는 문제](01_사용자_매뉴얼.md#자주-생기는-문제)를 확인한다.

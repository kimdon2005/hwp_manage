# 사용자 매뉴얼 — 컴퓨터를 잘 몰라도 따라 하는 방법

이 프로그램은 여러 개의 HWPX 파일을 단원별·책 전체로 합치고, 그림이 빠지지 않았는지 검사한 뒤 제출용 폴더와 ZIP 파일을 만든다.

평소에는 터미널 명령을 직접 입력할 필요가 없다. 아래 순서대로 폴더를 내려받고 Codex에 준비된 문장을 한 번 붙여 넣으면 된다.

## 먼저 알아둘 세 가지

- `HWPX`는 한컴오피스 한글에서 열 수 있는 문서 형식이다.
- 원본 파일은 `국어 자료 변형 중간모음터`에 넣는다. 프로그램은 이 원본을 수정하거나 삭제하지 않는다.
- `.hwp` 파일은 자동으로 바꾸지 않는다. 한글에서 **파일 → 다른 이름으로 저장 → 한글 표준 문서(*.hwpx)**로 저장한 뒤 사용한다.

## 1단계: 프로그램 폴더 받기

1. 인터넷에서 [hwp_manage GitHub](https://github.com/kimdon2005/hwp_manage)를 연다.
2. 초록색 **Code** 버튼을 누른다.
3. **Download ZIP**을 누른다.
4. 받은 `hwp_manage-main.zip`을 더블 클릭해 압축을 푼다.
5. 압축을 푼 `hwp_manage-main` 폴더를 문서나 바탕화면처럼 찾기 쉬운 곳으로 옮긴다.

Git 사용법을 아는 사람은 다음 명령으로 받아도 된다.

```bash
git clone https://github.com/kimdon2005/hwp_manage.git
```

## 2단계: Codex에서 폴더 열기

1. Codex를 실행한다.
2. **폴더 열기(Open Folder)**를 누른다.
3. 방금 압축을 푼 `hwp_manage-main` 폴더를 선택한다.
4. 왼쪽 파일 목록에 `README.md`, `AGENTS.md`, `scripts`가 보이는지 확인한다.

`hwp_manage-main`의 바깥 폴더나 `scripts` 폴더만 열면 안 된다.

## 3단계: 기본 세팅 프롬프트 붙여 넣기

[Codex 기본 세팅 프롬프트](08_Codex_기본세팅_프롬프트.md)를 열고 **“복사할 프롬프트”** 상자 안의 내용을 처음부터 끝까지 복사한다. Codex 채팅창에 붙여 넣고 전송한다.

Codex가 다음 작업을 자동으로 한다.

1. 현재 폴더와 운영체제를 확인한다.
2. 필요한 프로그램이 준비됐는지 확인한다.
3. 전용 실행 환경을 설치한다.
4. 자동 테스트를 실행한다.
5. 합성 샘플을 병합하고 결과를 검증한다.
6. 내 파일을 넣을 `사용자작업` 폴더를 만든다.

`자동 테스트 통과`, `샘플 검증 통과`, `사용자작업 폴더 준비 완료`라는 보고를 받으면 기본 세팅이 끝난 것이다.

Python이 설치되어 있지 않으면 Codex가 설치가 필요하다고 알려 준다. 이 경우 Codex가 제시한 공식 설치 방법을 한 번 수행한 뒤 같은 프롬프트를 다시 보내면 된다.

## 4단계: 내 HWPX 파일 넣기

Codex가 만든 다음 폴더를 Finder(macOS) 또는 파일 탐색기(Windows)에서 연다.

```text
hwp_manage-main/
└── 사용자작업/
    └── 목표2/
        └── 국어 자료 변형 중간모음터/
```

그 안에 `책 이름` 폴더와 `1단원`, `2단원` 같은 단원 폴더를 만든다. 예시는 다음과 같다.

```text
국어 자료 변형 중간모음터/
└── 비상 박영민/
    ├── 1단원/
    │   ├── 1.1_학습지.hwpx
    │   └── 1.2_정답과 해설.hwpx
    └── 2단원/
        ├── 2.1_학습지.hwpx
        └── 2.2_예시답안.hwpx
```

파일 앞 번호가 합쳐지는 순서다. 문제 다음에 정답이 나오게 하려면 문제와 정답 번호도 그 순서로 붙인다.

정답으로 분류되는 대표 이름은 `정답`, `정답과 해설`, `예시 답안`, `예시답안`, `예시 답안 및 평가 기준`이다.

## 5단계: Codex에게 실제 작업시키기

파일을 모두 넣은 뒤 아래 문장을 그대로 Codex에 보낸다. 책 이름을 입력하지 않아도 Codex가 폴더 안의 책을 찾아 처리한다.

```text
AGENTS.md와 docs/00_총정리_목차.md를 먼저 읽어줘.
사용자작업 폴더에 넣어 둔 모든 책을 확인하고, 원본은 절대 수정하거나 삭제하지 마.
각 책에 대해 doctor와 inventory를 실행해 입력 순서와 정답 분류를 먼저 확인하고,
문제가 없으면 pipeline으로 단원별 파일, 전체 파일, 제출용 폴더와 ZIP을 만들어줘.
마지막에는 verify를 별도로 다시 실행해 모든 passed가 true인지 확인해줘.
오류가 있으면 결과를 완성됐다고 말하지 말고 원인과 내가 해야 할 일을 쉬운 말로 알려줘.
성공하면 결과물이 만들어진 폴더 위치와 검사 결과를 책별로 짧게 정리해줘.
PDF 조각 폴더에 PDF가 있으면 --pdf 옵션으로 PDF도 함께 만들어줘.
```

기존 결과물이 있으면 새 작업 전에 자동으로 백업된다. 따라서 같은 작업을 다시 실행해도 이전 결과를 확인할 수 있다.

## 6단계: 완성 파일 찾기

결과는 다음 위치에 생긴다.

```text
사용자작업/목표2/국어 자료 최종본 모음/
├── 0. 전체 파일 모음/책 이름_전체.hwpx
├── 1. 책 이름 작업용/                 # 검사 보고서와 백업
├── 2. 책 이름 제출용/                 # 단원별 HWPX와 전체 HWPX
└── 책 이름.zip                        # 제출용 폴더와 같은 내용
```

보통 전달할 것은 `2. 책 이름 제출용` 폴더와 `책 이름.zip`이다.

PDF도 함께 만들고 싶다면 다음처럼 조각 PDF를 넣는다.

```text
사용자작업/목표2/국어 자료 PDF 조각/
└── 비상 박영민/
    ├── 1단원/*.pdf
    └── 2단원/*.pdf
```

실제 작업 프롬프트에 포함된 지시에 따라 PDF가 발견되면 Codex가 `--pdf` 옵션을 사용한다.

## 7단계: 한글에서 마지막으로 눈으로 확인하기

프로그램 검사가 통과해도 최종 제출 전에는 한컴오피스 한글에서 다음 부분을 직접 확인한다.

1. 전체 파일의 첫 페이지
2. 각 단원이 시작하는 부분
3. 그림이 많은 중간 페이지와 뒤쪽 페이지
4. 마지막 페이지

그림이 빈칸으로 보이거나 문서 복구 창이 뜨면 파일을 다시 저장하지 말고 Codex에 다음처럼 알려 준다.

```text
사용자작업의 결과 중 "책 이름_전체.hwpx"에서 그림이 깨져 보여.
원본과 결과의 섹션별 이미지 해시, BinData 참조, manifest를 비교해 원인을 진단해줘.
원본은 수정하지 말고 고친 결과를 새로 만든 뒤 pipeline과 verify를 다시 실행해줘.
```

## 자주 생기는 문제

### Codex가 “저장소 폴더가 아니다”라고 할 때

Codex에서 현재 연 폴더가 잘못된 것이다. `README.md`와 `AGENTS.md`가 바로 보이는 `hwp_manage-main` 폴더를 다시 연다.

### Python이 없다고 할 때

Codex가 안내하는 Python 공식 설치 페이지에서 Python 3.10 이상을 설치한다. 설치가 끝나면 Codex를 다시 열고 기본 세팅 프롬프트를 다시 보낸다.

### `.hwp` 파일만 가지고 있을 때

원본을 한글로 열고 **다른 이름으로 저장**에서 `.hwpx` 형식을 선택한다. 원본 `.hwp`는 지우지 않는다.

### `passed: false`가 나올 때

완성된 것으로 사용하지 않는다. Codex에 오류 보고서의 경로를 알려 주고 원인 진단을 요청한다.

### 프로그램을 새 버전으로 바꿀 때

먼저 `사용자작업` 폴더를 다른 곳에 복사해 둔다. Git으로 받은 경우 Codex에 “내 변경과 사용자작업을 보존하고 원격 main을 fast-forward 방식으로 업데이트한 뒤 자동 테스트를 다시 실행해줘”라고 요청한다. ZIP으로 받았다면 새 ZIP의 압축을 다른 폴더에 풀고, 백업한 `사용자작업`만 새 폴더로 옮긴 다음 기본 세팅 프롬프트를 실행한다.

## 직접 명령을 사용하고 싶은 경우

컴퓨터 사용에 익숙한 사람만 [전체 재현 절차](02_전체_재현_절차.md)를 참고한다. 일반 사용자는 Codex 프롬프트만 사용해도 된다.

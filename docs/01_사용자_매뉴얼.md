# 사용자 매뉴얼

## 1. 준비물

- macOS 또는 Windows
- Python 3.10 이상
- Git
- 병합할 HWPX 파일
- PDF 병합 시 PDF 조각과 PyMuPDF 의존성
- HWP를 HWPX로 바꿀 때는 한컴오피스 한글 권장

프로그램은 `.hwp`를 임의 변환하지 않는다. 한글에서 `다른 이름으로 저장`을 이용해 `한글 표준 문서 (*.hwpx)`로 저장한 파일을 넣는다.

## 2. 설치

```bash
git clone https://github.com/kimdon2005/hwp_manage.git
cd hwp_manage
```

macOS/Linux:

```bash
sh scripts/setup.sh
```

Windows PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

설치 스크립트는 `.venv`를 만들고 `lxml`, `PyMuPDF`, `pytest`와 본 프로그램을 설치한 뒤 자동 테스트를 실행한다.

## 3. 샘플 실행

macOS/Linux:

```bash
sh scripts/run_sample.sh
```

Windows PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_sample.ps1
```

성공하면 샘플 작업폴더에 다음이 생긴다.

```text
목표2/국어 자료 최종본 모음/
├── 0. 전체 파일 모음/샘플 교과서_전체.hwpx
├── 1. 샘플 교과서 작업용/_reports/*.json
├── 2. 샘플 교과서 제출용/
│   ├── 1단원.hwpx
│   ├── 2단원.hwpx
│   └── 샘플 교과서_전체.hwpx
└── 샘플 교과서.zip
```

## 4. 내 파일 넣기

아래처럼 단원 폴더를 만든다.

```text
내작업/
└── 목표2/
    └── 국어 자료 변형 중간모음터/
        └── 책 이름/
            ├── 1단원/
            │   ├── 1.1_학습지.hwpx
            │   └── 1.2_정답.hwpx
            └── 2단원/
                └── 2.1_학습지.hwpx
```

파일명 앞 번호가 실제 병합 순서다. `1.2` 다음 `1.10` 같은 이름도 자연 정렬된다. 문제와 정답을 붙여야 하면 정답 파일 번호를 대응 문제 바로 뒤 번호로 정한다.

환경 확인:

```bash
python -m hwp_manage doctor --workspace "내작업"
```

중간모음터 원본의 문서 종류, 정답 판정, HWP 변환 대기 목록이 필요하면 먼저 실행한다.

```bash
python -m hwp_manage inventory --workspace "내작업" --book "책 이름" --report "목록.json"
```

병합과 제출 패키지 생성:

```bash
python -m hwp_manage pipeline --workspace "내작업" --book "책 이름"
```

기존 최종본이 있으면 `1. 책 이름 작업용/_work/backups/실행시각/`에 제출용 폴더, ZIP, 전체 파일 모음 복사본을 먼저 백업한다. 디스크 여유를 확인한 뒤 백업을 의도적으로 생략하려면 `--no-backup`을 붙인다.

최종 재검증:

```bash
python -m hwp_manage verify --workspace "내작업" --book "책 이름"
```

결과 JSON의 모든 `passed`가 `true`여야 한다.

## 5. PDF도 함께 만들기

```text
내작업/목표2/국어 자료 PDF 조각/책 이름/1단원/*.pdf
내작업/목표2/국어 자료 PDF 조각/책 이름/2단원/*.pdf
```

```bash
python -m hwp_manage pipeline --workspace "내작업" --book "책 이름" --pdf
```

단원 PDF와 전체 PDF는 원본 조각에서 각각 직접 만든다. 단원 완성 PDF를 전체 PDF의 입력으로 다시 쓰지 않는다.

## 6. 개별 검사와 수동 병합

```bash
python -m hwp_manage inspect "파일1.hwpx" "파일2.hwpx"
python -m hwp_manage merge --input "파일1.hwpx" "파일2.hwpx" --output "합본.hwpx" --title "합본"
```

## 7. Codex로 실행

저장소 폴더를 Codex에서 연 뒤 다음처럼 요청한다.

```text
AGENTS.md와 docs/00_총정리_목차.md를 읽고,
내작업 폴더의 책 이름을 doctor → pipeline → verify 순서로 처리해줘.
```

Codex는 저장소의 `AGENTS.md`에 따라 원본을 보존하고 검증 결과를 확인해야 한다.

## 8. 한컴에서 마지막 확인

프로그램 검사는 ZIP/XML과 보존 해시를 확인한다. 최종 제출 전에는 한컴오피스에서 전체본을 열어 첫 페이지, 단원 경계, 그림이 많은 중간·뒤쪽, 마지막 페이지를 직접 확인한다. Windows에서는 한컴 자동화가 가능하면 실제 열림 검사도 추가한다.

## 시스템이 하는 일

```text
단원별 개별 HWPX
  → 입력 파일 구조·이미지 참조 검사
  → 단원 합본 생성
  → 병합 전후 섹션·본문·이미지·BinData 보존 비교
  → 단원 합본을 책 전체본으로 병합
  → 0. 전체 파일 모음에 전체본 복사
  → 2. 책 이름 제출용 구성
  → 책 이름.zip 생성
  → ZIP CRC·파일별 SHA-256 재검증
```

PDF 조각이 있으면 `--pdf`로 단원·전체 PDF를 만들고 기존 하단 번호 영역을 가린 뒤 연속 번호를 한 번만 넣는다.

## 표준 폴더

```text
작업폴더/
└── 목표2/
    ├── 국어 자료 변형 중간모음터/
    │   └── 책 이름/
    │       ├── 1단원/*.hwpx
    │       └── 2단원/*.hwpx
    ├── 국어 자료 PDF 조각/                 # --pdf 사용 시 선택
    │   └── 책 이름/{n}단원/*.pdf
    └── 국어 자료 최종본 모음/             # 프로그램이 생성
```

## 절대 원칙

- `.hwp` 원본은 자동으로 수정·삭제·이동하지 않는다.
- 병합은 검증된 `.hwpx`만 입력으로 받는다.
- 파일명 순서는 NFC 정규화 후 자연 정렬한다.
- 이미지 ID는 연쇄 문자열 치환하지 않고 XML 속성의 원래 값에서 새 값으로 한 번만 바꾼다.
- 입력 파일 한 개의 모든 섹션을 결과의 독립 섹션으로 보존한다.
- 검증 실패 결과는 최종 파일로 교체하지 않는다.
- 공개 저장소 샘플에는 실제 출판사 파일을 사용하지 않는다.

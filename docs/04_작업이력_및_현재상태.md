# 작업 이력 및 현재 상태

기준일: 2026-09-11

## 대상

메인 목적 폴더는 `목표2`이며 최종 대상 책은 다음 6권이다.

1. 독서와 작문 - 미래엔 평가문제
2. 문학과 영상 - 천재(김)
3. 비상 박영민
4. 천재 - 노미숙
5. 천재 - 정
6. 해냄

## 완료된 작업

### 최종 폴더 평면화

- `0. 전체 파일 모음`
- `1. 책 이름 작업용`
- `2. 책 이름 제출용`
- `책 이름.zip`

제출용 폴더의 내용물만 ZIP에 넣는 구조로 6권을 정리했다.

### 해냄 정답 판정 수정

- `정답과 해설`을 정답으로 포함했다.
- `예시 답안`, `예시답안`, `예시 답안 및 평가 기준`을 정답으로 포함했다.
- 대응 문제 바로 뒤에 정답이 오도록 순번을 다시 부여했다.
- 총 124개 문서 HWPX를 변형 중간모음터에 맞췄다.
- 정답 문서 58개 인접 배치를 확인했다.
- 4개 단원과 전체 HWPX/PDF, 제출용 폴더, 전체 파일 모음, ZIP을 갱신했다.
- 해냄 전체는 HWPX 124개 섹션, PDF 357쪽으로 기록됐다.

### 전체 HWPX 이미지 무결성 검사

- 제출용 HWPX 31개를 전수 검사했다.
- 단원 합본은 개별 HWPX와, 책 전체 합본은 단원 합본과 섹션별 이미지 SHA-256를 비교했다.
- 추가로 손상된 전체본을 발견해 재구성했다.
  - `문학과 영상 - 천재(김)_전체.hwpx`: 불일치 섹션 2, 누락 참조 15
  - `천재 - 정_전체.hwpx`: 불일치 섹션 50, 누락 참조 205
- 사용자 제보로 먼저 수정한 `비상 박영민_전체.hwpx`도 포함해 총 3개 전체본을 새 병합기로 다시 만들었다.
- 수정 후 31/31 이미지 불일치 0, 누락 참조 0으로 확인했다.
- 6개 ZIP 내부 파일과 제출용 원본의 SHA-256가 일치했다.
- 한컴 렌더링 기록:
  - 문학과 영상 - 천재(김): 75쪽
  - 천재 - 정: 251쪽
  - 비상 박영민: 344쪽

### 비상 박영민 제출용 재확인

- `2. 비상 박영민 제출용/비상 박영민_전체.hwpx` 존재 확인
- `pdf/비상 박영민_전체.pdf` 존재 확인
- 전체 HWPX 83개 섹션, 이미지 누락·불일치 0
- 제출용 10개와 ZIP 10개 파일의 해시 일치

### Google Drive 검증 이력

2026-08-31 당시 Drive 69개와 로컬 대상 68개를 대조해 68개가 바이트 단위로 일치했고, Drive에만 `2. 천재 - 정 제출용/.DS_Store`가 1개 있었다. HWPX 31개와 내부 이미지 2,047개, ZIP 6개가 당시 로컬과 일치했다.

그 뒤 2026-09-03~04에 해냄과 전체본 3개가 수정됐다. 2026-09-04 Google Drive 플러그인으로 갱신을 시도했지만 커넥터가 `USER_NOT_LOGGED_IN` 상태여서 실제 업로드는 수행되지 않았다. 따라서 현재 Drive가 최신 로컬 수정본과 같은지는 다시 연결한 뒤 재검증해야 한다.

## 현재 로컬 기준

- 제출용 HWPX 31개: 마지막 전수 검사 통과
- 책별 전체본 6개: `0. 전체 파일 모음`과 제출용 복사본 해시 일치 기록
- 책별 ZIP 6개: CRC 및 내부 해시 일치 기록
- 수정 전 백업은 각 책 작업용 `_work/backup_*`에 보존

## 남은 운영 작업

1. Google Drive 커넥터를 다시 연결한다.
2. 6개 `2. * 제출용` 폴더와 6개 ZIP을 최신 로컬본으로 교체한다.
3. Drive에서 다시 내려받아 68개 대상의 SHA-256를 비교한다.
4. 원격 `.DS_Store`가 남아 있으면 정확한 파일 ID를 확인한 뒤 제거한다.
5. 중요한 전체본은 최종 제출 환경의 한컴오피스 버전에서도 대표 페이지를 한 번 더 확인한다.

## 기록 원칙
